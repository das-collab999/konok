# Фотографии мест

Положите сюда снимки: `sonkul-1.jpg`, `arslanbob-1.jpg` и так далее.
Потом в `src/data/places.ts` у нужного места допишите строку:

```ts
photo: "/photos/sonkul-1.jpg",
```

Пока фотографии нет, рисуется горный пейзаж — сайт выглядит целым в любом случае.
Лучше всего смотрятся вертикальные снимки (пропорции примерно 4:5) шириной от 1600 пикселей.
